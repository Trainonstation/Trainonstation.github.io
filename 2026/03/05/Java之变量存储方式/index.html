栈变量

与几乎所有的编程语言一样，将要被执行的main函数中的所有变量都存储在栈中，并且均为前面提及的静态变量

可以正常使用并改变变量的值，实例对象也是如此

堆变量

那么在main函数以外的变量和函数存储在哪里呢？自然是在我们的老朋友堆里面

Git大学习(Arch(WSL2))——配置与保存

起因

很久以前就想学git试试创建版本管理和项目拉取，但是总是因为网络问题之类的失败掉，现在已经万事俱全了，打算试一下这次能不能学会😀

准备工作

  • Github账户
  • archlinux(WSL2)
  • Git()

安装

在WSL2中，Git是预装的，不过仍然建议更新一下

开始

我们先直接跳到菜鸟的网站进行学习，这里也推荐一下这个网站给各位初学者（如果你是的话），里面几乎包含了几乎所有主流互联网程序的开发教程。

Git命令

配置

开发人员的天堂与地狱——配置!

Git的配置有两种方法，命令或是写配置文件，这里我们讲解前一种

配置路径与参数

配置文件的位置按照作用范围分三个地方：

路径 参数 介绍
/etc/gitconfig –system 系统级设置，所有用户默认的设置
{你的工作目录下}/.git/cofnig 无 当前项目的设置
~/.gitconfig –global 你的设置，在你的~目录及其以下目录下默认生效

配置命令

Git支持在配置中添加个人信息并在每次提交代码时附上这些信息：

修改后记得不要忘记看一看有没有完成修改，使用–list参数来查看当前的配置

总体流程

从工作开始git主要分一下几步(用我天池竞赛的项目为例)：

1.初始化项目，你的提示符中会多一个“master”字符，如果你使用了oh_my_zsh并使用了特殊的主题，还会显示特殊的颜色

应该有以下输出:

同时目录下多了一个.git目录

2.完成了一部分代码工作，将其存入暂存区，表示“这是这次修改的文件”,同时提示符中的“master”后会多一个“+”号

3.所有文件都修改完毕，整齐的放入本地仓库，此时仓库里就有了迄今位置代码修改的记录。如果以后代码发生了问题，可以通过本地仓库的记录一步一改回来。

这里遇到了一个小插曲

原来是我忘记修改默认的文本编辑器了！用先前的命令改一下

再次尝试，或弹出一个vim编辑页面（##开头是我的备注），用来为本次修改留下信息，方便自己或者其他人维护项目

编辑完成后直接wq保存，该文本会原封不动的保存到{你的工作目录}/.git/COMMMIT_EDITMSG

不过其实你可以用-m参数快速提交

4.把本地的仓库放到远程仓库里（相当于复制一份到远程仓库），日后无论在哪台机器上开发都可以快速把项目在本地构建起来。
不过在这之前要先有一个远程仓库才行啊!，所以我们先到GitHub.com，创建一个新仓库并复制url
使用命令remote add来添加这个仓库

然后提交分支
